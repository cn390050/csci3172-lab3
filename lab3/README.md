# Lab 3 - PuckStats

* Description: This applcation is an NHL stats dashboard, the NHL player stats data used for this apllication was collected from the scraper used from PuckFinder the application I created during Lab 2. The data includes player names, games, goals, assits and total points. The front end of this application uses React and Vite used as the server and build tool. Bootstrap was used for the styling and layout. The backend is built with Node.js and Express, using a REST API to fetch, add or delete player data. This application also allows you to click on the headers of the columns of the table and sort players based on those statistics in asc and desc order.
